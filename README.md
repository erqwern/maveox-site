# Mavoex Static — HTML + Tailwind версия

Полностью статическая версия сайта mavoex.site.

## Как запустить
1. Откройте `index.html` в любом браузере.
2. Для полного опыта: задеплоите папку на Netlify / GitHub Pages / Vercel (static).

## Особенности
- Tailwind via CDN (https://cdn.tailwindcss.com)
- Полностью ванильный JS (startup анимация, cycling ролей, мобильное меню, форма, копирование email)
- Все страницы портфолио/услуг/контакта и т.д.
- Изображения книг локально в `images/books/`
- TG ссылки сохранены как в оригинале (услуги → erqwern, остальные → ercqwern)

## Разница с Next.js версией
- Нет React/Framer Motion (заменено на CSS + чистый JS)
- Startup анимация и все взаимодействия работают нативно
- Очень лёгкий и быстрый
- Легко хостить где угодно

Сделано по просьбе автора как чистая HTML+Tailwind альтернатива.
